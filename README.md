# CryptoExchange Simulator

Локальный симулятор криптовалютной биржи с виртуальной торговлей и живым рынком. Проект объединяет React-интерфейс торгового терминала и Express API с хранением данных в JSON.

## Возможности

- рынок BTC, ETH, SOL, BNB и DOGE с автоматически меняющимися котировками;
- покупка и продажа активов с комиссией 0,1%;
- портфель с P&L, средней ценой покупки и распределением активов;
- история сделок с поиском и фильтрами;
- ценовые уведомления с автоматическим срабатыванием и in-app центром событий;
- рейтинг демонстрационных трейдеров;
- переключение аккаунтов без регистрации;
- адаптивный интерфейс для компьютера и мобильных устройств;
- автоматическое сохранение балансов и операций.

## Запуск

Требуется Node.js 18 или новее.

```bash
npm install
npm run dev
```

Интерфейс откроется на `http://localhost:5173`, API — на `http://localhost:3001`.

## Команды

```bash
npm run dev    # frontend и backend в режиме разработки
npm run build  # production-сборка frontend
npm test       # тесты Vitest
npm run reset  # вернуть демонстрационные данные к начальному состоянию
```

## Структура

- `frontend/` — React, Vite, Tailwind CSS, Recharts и Lucide;
- `backend/` — Express API, бизнес-логика и JSON-хранилище;
- `tests/` — базовые сценарии торговли и расчёта портфеля.

После `npm run reset` перезапустите сервер разработки, если он уже был запущен.
